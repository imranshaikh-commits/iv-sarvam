# Shilpi in one page

Shilpi drafts an IV technical proposal from a client's RFP or SOW, grounded in
IV's past proposals. You review it; you send it. Nothing reaches a client
without your edit.

## 1. Start

Open **https://13-206-20-25.sslip.io**, sign in, and start a **new chat** for
each deal (one chat = one proposal).

## 2. Give it the deal

- **Have the RFP/SOW:** attach it (PDF or DOCX) and say what it is, e.g.
  *"New proposal for ESNAD, Ping Identity and Saviynt."* Scanned PDFs are fine;
  reading them takes a few minutes.
- **No document:** say *"new implementation proposal for <client>, <vendor>"*
  (or *migration*, or *MSS*) and answer the interview. You can paste all your
  answers in one message, in any format.

## 3. Fill the gaps

Before drafting, Shilpi lists what it could not find (user counts, environments,
integrations, timelines). Answer what you can; say **generate anyway** to draft with the gaps.
Every gap you leave becomes an `[SME REVIEW]` marker in the document.

## 4. Approve the diagrams

Shilpi proposes architecture diagrams one at a time. Reply **approve**,
**regenerate**, or say what is wrong ("PAM is Saviynt, not CyberArk"). Only
approved diagrams go into the document.

## 5. Get the document

Drafting takes about 30-40 minutes. The reply links a DOCX and a PDF and lists
the **compliance requirements still to confirm**: those answered "confirmed
during Discovery" or not covered by any section.

## 6. Before it goes to the client

Search the DOCX for, and resolve, every:

- **`[SME REVIEW]`** marker: evidence ran out; write it or delete it.
- **"To be confirmed"** in tables, especially the compliance matrix.
- **Commercials:** licence quantities, prices and payment milestones are drafts.
- **Similar Experience:** only engagements IV delivered are listed, and clients
  are named only where IV already names them; check the wording.
- **Diagrams and figures:** user counts, versions and system names match the RFP.

Then read it once end to end as the client would.

## Good to know

- Shilpi records who created each proposal and approved each diagram.
- Problems: tell Imran, with the chat's name and the time.
